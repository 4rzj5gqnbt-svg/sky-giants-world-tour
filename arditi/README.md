# Arditi

Gioco tattico stealth in 3D in stile Commandos sugli Arditi della Grande Guerra.
Sito statico generato da `build-web.sh`: `index.html`, `three.min.js` (Three.js r128), font locali (licenza OFL, in `fonts/`), manifest e service worker per giocare offline, e `arditi-offline.html` (tutto in un file).
