# Corpi Scelti

Gioco tattico stealth in 3D sui corpi scelti italiani delle due guerre mondiali.
Sito statico generato da `build-web.sh`: `index.html`, `three.min.js` (Three.js r128), font locali (licenza OFL, in `fonts/`), manifest e service worker per giocare offline, e `corpi-offline.html` (tutto in un file).
